- **آخرین بازبینی گزارش:** ۲۰۲۶-۱۰-۳۰
- **مبنای بررسی:** `dev` در کامیت `c4f6d7736cc0cd15140b82e306434b6fd74e97af`، به‌علاوهٔ تغییرات [تکمیل متن مصوب](reports/2026-10-30-approved-introductions.md)؛ وضعیت ادغام و آزمون تغییرات را در PR مربوط ببینید.

## موارد موردنیاز از مدیرکل

- خرید لایسنس سازمانی IRANSans و تحویل امن فایل‌ها پیش از استفادهٔ نهایی؛ تا آن زمان فونت سیستمی موقت حفظ می‌شود.
- برای پایگاه‌دادهٔ توسعهٔ قبلی، `npm run seed` را دوباره اجرا کنید؛ اگر رکورد `track-record-intro` از قبل وجود داشته باشد، seed آن را بازنویسی نمی‌کند.
- هماهنگی مرحلهٔ بعد شامل فرم‌ها و اتصال‌ها؛ متن CTAهای وابسته به فرم فعلاً غیرفعال است.
