# گزارش توسعه: اصلاح شبکهٔ داخلی پیش‌نمایش

- **تاریخ:** ۲۰۲۶-۱۰-۲۹؛ ساعت محیط و GitHub در نشست پیشین تاریخ دیگری نشان داده‌اند و اختلاف تأیید نشده است.
- **مبنا:** `dev` پس از PR #19، commit `dde1e5383793b41e61977027d0790e15593f8d9b`؛ تصمیم صریح مدیریت پروژه دربارهٔ منع انتشار پورت App روی میزبان.
- **وضعیت:** اصلاح در حال بررسی؛ آمادهٔ merge یا اجرای VPS نیست.

## خلاصه و اقدامات

طرح Compose ثابت شبکهٔ داخلی جداگانه برای DB و ارتباط gateway ایجاد می‌کند؛ App به هر دو و DB فقط به شبکهٔ DB متصل می‌شوند و هیچ پورت App/DB روی میزبان منتشر نمی‌شود. helper نصب نخست و انتشارهای بعدی ساختار دقیق service، volume، شبکه و نبود پورت و runtime شبکه را ردگیری و فایل ناشناخته را رد می‌کنند. healthcheck موجود از `docker compose exec` داخلی استفاده می‌کند و به پورت میزبان وابسته نیست. `FixedRunner.verify_helpers` دست‌نخورده است.

installer فعلی برای گذار محدود نصب واقعیِ `f18b315` به helper شبکه‌ای گسترش یافته: نسخهٔ قبلی helperها و Compose قبلی با hash ثابت حفظ می‌شوند و خطای قابل‌دریافت پس از تعویض rollback می‌شود. state، secrets و volumeها دست‌نخورده می‌مانند و وضعیت غیرمنتظره باعث توقف می‌شود. آثار وقفهٔ برق/کشتن فرایند به بررسی امن نیاز دارند. فایل Compose فعلی VPS هنوز تغییر نکرده است.

Caddyfile و routeهای بازبینی‌شده به تنظیمات افزوده شده‌اند؛ CI جداگانه Caddy واقعی و app واقعی را روی شبکهٔ داخلی با gate **مصنوعی** اجرا می‌کند. این آزمون OAuth/GitHub واقعی، اتصال VPS، TLS عمومی یا پذیرش کاربر نیست.

## آزمون‌ها و شواهد

| آزمون | محیط | وضعیت |
|---|---|---|
| تست واحد توپولوژی، backend، transaction و internal health | محلی، بدون Docker | موفق؛ آزمون runtime نیست |
| ارتقا، نصب نخست و rollback با helper نصب‌شده | GitHub Actions دورریختنی | در انتظار CI روی این تغییر |
| Caddy واقعی و app واقعی، gate مصنوعی | GitHub Actions دورریختنی | در انتظار CI روی این تغییر |
| VPS | گزارش مالک قبل از این تغییر | helperهای نسخهٔ قبلی ارتقا و Compose loopback آماده شدند؛ app/gate شروع نشده‌اند. این اصلاح هنوز روی VPS اجرا نشده است. |

## خطرها و پیگیری

مسیر عملیاتی gateway و اثبات هویت و اتصال Caddy هنوز به زنجیرهٔ helper اضافه نشده است. helper فعلی به‌طور fail-closed هر peer دیگری روی شبکهٔ gateway را رد می‌کند؛ در نتیجه این شاخه هنوز به تنهایی برای استقرار gate آماده نیست. راه‌اندازی و ادغام نباید پیش از تکمیل این کنترل و CI موفق انجام شود. OAuth واقعی، DNS، TLS، پذیرش Staff/API/media، انتقال backup به رایانهٔ مالک و restore عملیاتی نیز بازند. پیش از Caddy تداخل پورت‌های ۸۰/۴۴۳ مجدداً بررسی شود؛ هیچ داده، شبکه یا سرویس موجود حذف/توقف نشود.

## تصمیم‌ها و پیگیری Vault

مدیریت پروژه صریحاً حفظ منع پورت میزبان و رفع عیب در همان زنجیره را تأیید کرده است؛ مرجع Vault فقط خواندنی است. در نشست Vault، اصلاح متن/ثبت این تصمیم اجرایی در `META-INT-140` و رفع تعارض ثبت‌شده پیگیری شود؛ این گزارش جایگزین مرجع نیست. برای DNS فقط تأیید رسمی نشانی امن پنل و محل مدیریت zone از پشتیبانی لازم است؛ nameserver و دیگر رکوردها تغییر نمی‌کنند.
