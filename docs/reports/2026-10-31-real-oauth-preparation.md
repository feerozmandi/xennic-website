# گزارش توسعه: آماده‌سازی آزمون OAuth واقعی محلی

- **تاریخ:** ۲۰۲۶-۱۰-۳۱
- **مبنا:** نتیجهٔ [آزمون gate مصنوعی](2026-10-31-synthetic-preview-test-result.md)، سایت `418de2b5b3a272e79a824ccde5411dc25f1002cc` و بستهٔ زیرساخت `1.1.2` در `ccbaaded6244fb9228fcce6cbe22c67b65f896b4`.
- **وضعیت:** مالک ایجاد App آزمایشی مستقل با callback سازگار را در گفتگو تأیید کرد؛ ساخت App، انتخاب نهایی scope و اجرای آزمایش هنوز گزارش نشده است.

## خلاصهٔ مدیریتی

آزمون قبلی تنها gate مصنوعی را پوشش داد. مجوز ایجاد App مستقل به‌معنای نتیجهٔ موفق OAuth یا مجوز تغییر gate موجود، VPS یا DNS نیست. ساخت App در حساب GitHub به اقدام محلی صاحب حساب نیاز دارد.

## اقدامات و خروجی‌ها

- هدف callback آزمایشی `https://preview.xennic.ir/oauth2/callback` است تا با Origin و کوکی host-only سایت baseline سازگار باشد. نمونهٔ قدیمی `localhost:18443` یا Compose مرجع قدیمی بدون تغییر دوباره استفاده نمی‌شوند.
- فقط حساب تأییدشده باید از دروازه عبور کند؛ این محدودیت در تنظیم OAuth2 Proxy و آزمون مستقل آن اعمال و بررسی می‌شود، نه صرفاً با نام‌گذاری App یا email wildcard.
- برای بررسی اصل کمترین دسترسی، `user:email` کاندید اولیهٔ آزمایشی است، نه تضمین سازگاری یا scope نهایی. کد provider مربوط به نسخهٔ بسته فراخوانی‌های org/team نیز دارد؛ اگر API به دسترسی بیشتری نیاز داشت، علت بررسی و پیش از هر مجوز گسترده‌تر به مالک اعلام می‌شود. `read:org` برای App تازه خودکار تأیید نشده است.
- هیچ Client Secret، token، code، cookie یا فایل خصوصی در مخزن یا گفتگو قرار نمی‌گیرد. راه‌اندازی باید در lab مستقل با egress موردنیاز GitHub، بدون تغییر gate قبلی و با مسیریابی و trust محدود به آزمایش طراحی و آزموده شود.

## آزمون‌ها و شواهد

| آزمون یا بررسی | محیط و تاریخ | نتیجه |
|---|---|---|
| تأیید ساخت App مستقل | گفتگو با مالک، ۲۰۲۶-۱۰-۳۱ | تأیید شده؛ خود App هنوز ساخته‌شده گزارش نشده است |
| gate مصنوعی و Payload واقعی | رایانهٔ مالک، ۲۰۲۶-۱۰-۳۱ | طبق گزارش قبلی موفق؛ اثبات OAuth واقعی نیست |
| OAuth، callback، GitHub egress، مرورگر و دو دستگاه | محیط واقعی آزمایش | اجرا نشده؛ نتیجه نامعلوم است |

## ریسک‌ها و کارهای باز

- ساخت App، تزریق امن مقادیر، CA و نگاشت host موقتی در مرورگر مجزا و شبکهٔ egress واقعی باید بدون استفاده از داده یا سرویس فعال پیشین انجام شوند. اجرای آزمایش واقعی تنها پس از آماده‌سازی مستقل انجام می‌شود.
- scope نهایی، نتیجهٔ حساب دوم، replay نشست gate، عدم bypass، HTTPS عمومی، پذیرش موبایل و دسکتاپ، ظرفیت، backup و rollback باز است. به علت فقدان runtime، هیچ‌یک تأییدشده فرض نمی‌شوند.

## تصمیم‌ها و درخواست از مدیرکل

مالک App آزمایشی را در رابط GitHub حساب خود ثبت کند و فقط انجام‌شدن کار را گزارش کند؛ اطلاعات محرمانه یا OAuth code در گفتگو ارسال نشود. هر دسترسی اضافی یا تغییر فراتر از این آزمایش جداگانه اعلام می‌شود. هیچ مجوز VPS یا DNS داده نشده است.

## پیگیری Vault

Vault فقط خواندنی باقی ماند. پس از آزمون و تصمیم نهایی، callback، scope و طرح حفاظت در نشست مستقل Vault پیگیری شود؛ گزارش مخزن جایگزین ثبت رسمی تصمیم نیست.
