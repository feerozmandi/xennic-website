# سیاست موقت backup پیش‌نمایش آزمایشی

- **تصمیم مالک، ۲۰۲۶-۱۱-۰۱:** خرید Hetzner تصویب نشده و شرط پیش‌نمایش نیست. برای staging فاقد دادهٔ واقعی مشتری، backup هماهنگ و رمزنگاری‌شدهٔ DB/media روی VPS، کپی دستی به رایانهٔ مالک در راه‌اندازی اولیه و نقاط مهم، و آزمون بازیابی دادهٔ آزمایشی مجاز است. انتقال خارج VPS دائمی یا خودکار تضمین نمی‌شود. پیش از استفادهٔ عملیاتی مقصد خارج VPS خودکار لازم است.
- **محدودهٔ کد:** `backup.json` خصوصی و root-owned باید صریحاً `transport: manual-local`، `environment: preview-staging-only`، `approved: true` و `no_real_customer_data: true` داشته باشد؛ `PREVIEW_ORIGIN` باید دقیقاً `https://preview.xennic.ir` باشد. identity برای آزمون restore لازم است. این مجوز تنها برای پروژه و مسیر ثابت preview است، نه production. عبارت نبود دادهٔ واقعی یک تعهد عملیاتی است، نه ابزاری که بتواند ماهیت شخصی تمام داده‌ها را تشخیص دهد؛ ورود دادهٔ واقعی مشتری به staging ممنوع است. تنظیمات غیرمجاز یا ناقص رد می‌شوند و حالت قبلی SFTP بدون این استثنا برقرار است.
- **ایمنی:** توقف writerها، snapshot هماهنگ، age، صحت محتوای DB/media و بازیابی DB ایزوله همچنان اجباری‌اند. فقط پس از restore موفق، رکورد محلی با `manual-offsite-pending` صادر می‌شود؛ این رکورد شاهد انتقال به رایانهٔ مالک نیست. هیچ داده‌ای در rollback خودکار restore نمی‌شود. نسخهٔ رمزنگاری‌شده و هش آن باید با مسیر امن و احراز هویت میزبان به رایانهٔ مالک منتقل و کپی/بازیابی آزمایشی بررسی شود؛ بدون انجام این مرحله ادعای نسخهٔ خارج VPS نشود. backup محلی معتبر پیش از هر migration روی دادهٔ موجود الزامی است.
- **آزمون و حدود:** آزمون‌های محلی readiness و پروتکل از ورودی‌های مصنوعی استفاده می‌کنند. در [CI 41282972314](https://github.com/feerozmandi/xennic-website/actions/runs/41282972314)، commit `79784a5fae5cd53d48b51351ce819fc1cf225e3f`، چهار job موفق شدند: helperهای نصب‌شده در runner دورریختنی backup محلی رمزنگاری‌شده، restore DB ایزوله، migration و activation را با دادهٔ آزمایشی اجرا کردند؛ کلید نادرست مانع ثبت backup شد و مسیر SFTP و rollback نیز آزموده شدند. GitHub و registry آن زنجیره مصنوعی‌اند و انتقال واقعی به رایانهٔ مالک ثابت نشده است. تأیید مالک دربارهٔ اثر انگشت SSH از پشتیبانی مستقل در [PR #14](https://github.com/feerozmandi/xennic-website/pull/14#issuecomment-6554398016) ثبت شده، اما این محیط در اتصال SSH پیام آغازین یا کلید دریافت نکرده و کلید ورود ندارد. هیچ اتصال یا تغییر VPS/DNS و هیچ انتقال backup واقعی انجام نشده است.
- **پیش‌نیازهای باز:** نخستین bootstrap در backend خودکار فعلی رد می‌شود و باید جداگانه و بدون ساخت رکورد سلامت جعلی بازبینی شود؛ backend و receiver همچنان disabled هستند. gate/OAuth، Staff، انزوای writerها، اعتبار تنظیمات، DNS authority و آزمون دو دستگاه باید عملیاتی بررسی شوند. استفاده از مسیر SSH خودکار یا استقرار بدون دسترسی امن و تنظیمات واقعی ادعا نمی‌شود. نامزد GHCR قبلی `ghcr.io/feerozmandi/xennic-website@sha256:e2108bc03a54445201292f31eb3ac448be96a371ac60dc8ab5e2f730c9605cbc` مربوط به commit `28aaa6f445520ffd4d0cf15f02dbc235c92403e8` است؛ تغییر کد سیاست، در صورت ادغام و نیاز به release جدید، باید زنجیرهٔ آزمون/انتشار مستقل خود را داشته باشد. `current-check` فقط tip فعلی `dev` را می‌پذیرد.
- **انتشار و verifier واقعی:** پس از ادغام PR #15، اجرای [push 41283756945](https://github.com/feerozmandi/xennic-website/actions/runs/41283756945) برای commit `449a135c3c4b3bd7b0e03163e63258b1396329a0` موفق شد و همان digest منتشرشده `ghcr.io/feerozmandi/xennic-website@sha256:dc684fb05653ab40409957334101e0db90abb555ef8a86212abba9ce80113e68` را برای `linux/amd64` آزمود. verifier همان کد dev در [CI 41284996367](https://github.com/feerozmandi/xennic-website/actions/runs/41284996367/job/124784412366) artifact واقعی run 71 را با token خواندنی بررسی کرد و تطبیق repository، commit، digest و معماری موفق شد. مرحلهٔ تشخیصی موقت از workflow حذف شده است. این شاهد استقرار یا دسترسی VPS نیست.
- **شروع نصب:** مالک گزارش کرد سه مسیر ثابت نصب و پروژه/volume با label دقیق `xennic-preview` در VPS موجود نیستند و `age` یافت نشد؛ گزارش فقط‌خواندنی و نقل مالک است. مرحلهٔ نخست شامل کنترل پیش‌نیازها و پورت‌های ۸۰/۴۴۳، دریافت کد با commit ثابت و بررسی SHA-256، نصب age در صورت نیاز و اجرای installer است. ایجاد تنظیمات، اجرای app، مهاجرت، DNS، SSH خودکار یا تغییر سرویس‌های دیگر بخشی از این مرحله نیست؛ نتیجهٔ اجرا هنوز از مالک دریافت نشده است.
