# گزارش توسعه: بررسی دسترسی Firefox به lab

- **تاریخ:** ۲۰۲۶-۱۰-۳۱
- **مبنا:** گزارش مالک از صفحهٔ Firefox، اسکریپت lab و [گزارش قبلی callback](2026-10-31-oauth-callback-diagnosis.md).
- **وضعیت:** مالک برای نشانی sign-in پیام `Server Not Found` گزارش کرد. خروجی listener تشخیصی، پروفایل جاری مرورگر و وضعیت جاری containerها گزارش نشده‌اند.

## خلاصهٔ مدیریتی

نشانی lab با تنظیم `network.dns.localDomains` فقط در پروفایل Firefox مخصوص آزمایش به loopback نگاشت می‌شود. DNS عمومی، فایل hosts و Firefox معمولی تغییر نکرده‌اند. بازشدن لینک در مرورگر یا پروفایل دیگر یک توضیح ممکن است، اما تا بررسی واقعی نباید علت قطعی فرض شود. بسته‌شدن lab یا اشکال پروفایل/شبکه نیز باید جداگانه بررسی شود.

## اقدام و شواهد

- مالک پیام عمومی شکست callback را پیش‌تر گزارش کرده بود؛ موفقیت login یا دریافت credential صحیح از این پیام ثابت نمی‌شود.
- گزارش جدید خطای مرورگر است؛ به‌تنهایی وضعیت واقعی gate، Caddy یا DNS پروفایل را ثابت نمی‌کند. راهنمای قبلی لینک قابل‌کلیک داشت که ممکن است در مرورگر پیش‌فرض باز شده باشد.
- بررسی پیشنهادی فقط سرویس‌های در حال اجرای همان project و کد HTTP درخواست بدون credential به `127.0.0.1` با CA مخصوص lab را گزارش می‌کند. همچنین تطبیق پروفایل باید در رابط Firefox بدون ارسال مسیر، cookie، URL callback یا screenshot بررسی شود.
- اجرای OAuth، restart، seed، migration و تغییر gate، پروفایل معمول، trust store سیستم، hosts، DNS یا VPS انجام نشد. اگر lab قبلاً بسته شده باشد، ادامهٔ مطمئن آن نیازمند بررسی وضعیت فایل و حجم‌های همان پروژه است، نه اجرای مجدد کورکورانهٔ اسکریپت اولیه.

## آزمون‌ها و ریسک‌ها

| مورد | زمان/محیط | نتیجه |
|---|---|---|
| پیام مرورگر | ۲۰۲۶-۱۰-۳۱، گزارش مالک | Server Not Found؛ محل پروفایل و وضعیت container نامعلوم |
| وضعیت HTTPS محلی و سرویس‌ها | رایانهٔ مالک | بررسی فقط‌خواندنی درخواست شده؛ نتیجه هنوز نامعلوم |
| login و callback | آزمایش واقعی | شکست گزارش شده؛ علت و HTTP status نامعلوم |
| OAuth، scope، دو دستگاه و پذیرش مرورگری | آزمایش واقعی | هنوز تأیید نشده‌اند |

## تصمیم‌ها و درخواست از مدیرکل

هیچ مجوز تازه‌ای برای بررسی خواندنی لازم نیست. تنها وضعیت غیرمحرمانهٔ سرویس‌ها، HTTP status و تطبیق پروفایل درخواست می‌شود؛ اطلاعات محرمانه و نشانی کامل callback در گفتگو ارسال نشوند. `read:org` و تغییر VPS/DNS همچنان مجاز نشده‌اند.

## پیگیری Vault

Vault فقط خواندنی است؛ علت و نتیجهٔ نهایی پس از آزمون واقعی و تأیید در نشست جداگانه پیگیری شود.
