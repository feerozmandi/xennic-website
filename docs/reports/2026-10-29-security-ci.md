# گزارش توسعه: بررسی امنیت، CI و تصمیم‌های مالک

- **تاریخ گزارش:** ۲۰۲۶-۱۰-۲۹
- **مبنای بررسی:** شاخهٔ `dev` در کامیت `6fd77fa0b1cee1cb6b3951be75a6ff6a2bd825a6`، به‌علاوهٔ تغییرات این گزارش؛ وضعیت PR این تغییرات را در GitHub بررسی کنید.
- **وضعیت تغییر:** نتیجهٔ ادغام و اجرای CI را در PR مربوط ببینید؛ گزارش محلی به‌تنهایی به‌معنای موفقیت CI در GitHub نیست.

## خلاصهٔ مدیریتی

مالک فیلدهای حداقلی CMS و ساختار صفحات را تأیید و رسیدگی به امنیت و آزمون Compose را مجاز کرد. دو علت مستقیم هشدارهای high با overrideهای هدفمند کاهش یافتند؛ هشدارهای متوسط و پایین و ریسک سازگاری بالادستی هنوز بازند. Workflow سادهٔ PR اضافه شد، ولی Docker برای آزمون Compose در این Sandbox موجود نبود.

## اقدامات و خروجی‌ها

- لینک Vault در README اصلی از `main` قدیمی به `dev` اصلاح شد.
- در بررسی Vault، `L2-MKT-003` نسخهٔ ۰.۲.۰ انتخاب IRANSans را تأیید می‌کند: خرید فقط از `fontiran.com` با لایسنس سازمانی، ممنوعیت کامیت فایل واقعی در مخزن عمومی، و فونت سیستمی تا زمان خرید. قواعد `.gitignore` برای فایل‌های فونت و مسیر خصوصی افزوده شد؛ نادیده‌گرفتن فایل محافظ مطلق در برابر افزودن اجباری نیست.
- `graphql-scalars` از `1.22.2` به `2.0.1` و `happy-dom` از `20.14.6` به `21.0.4` به‌صورت npm override تغییر کردند؛ نسخه‌های تثبیت‌شدهٔ Next.js و Payload تغییر نکردند. از `npm audit fix --force` استفاده نشد.
- Workflow `.github/workflows/ci.yml` برای همهٔ PRها `npm ci`، typecheck، lint و build را اجرا می‌کند؛ داده‌های محیطی آن فقط نمونهٔ غیرواقعی برای build هستند. در `dev` پیش از این تغییر، workflow `update-index` در این مخزن وجود نداشت؛ این Workflow جدید و مستقل است.
- آزمون سازگاری `npm run test:compat` اضافه شد؛ این آزمون در Workflow محدود فعلی اجرا نمی‌شود و باید جداگانه اجرا شود.

## ریسک‌ها و کارهای باز

- overrideها خارج از محدودهٔ پشتیبانی اعلام‌شدهٔ والد هستند. آزمون‌ها فقط مسیرهای محدود را پوشش می‌دهند؛ هنگام انتشار نسخهٔ سازگار بالادستی باید حذف یا بازبینی شوند.
- اجرای واقعی Compose در محیط دارای Docker، بررسی هشدارهای باقی‌مانده و بررسی CI در GitHub هنوز لازم‌اند.
- خرید مجوز سازمانی فونت و پیاده‌سازی محتوای واقعی، فرم‌ها و استقرار هنوز انجام نشده است.

## تصمیم‌ها و درخواست از مدیرکل

تأیید فیلدهای CMS و ساختار صفحات و مجوز رسیدگی به امنیت و Compose در گفتگوی ۲۰۲۶-۱۰-۲۹ از مالک دریافت شد. برای خرید فونت و فراهم‌شدن محیط Docker پیگیری لازم است؛ هماهنگی اولویت پیاده‌سازی محتوای واقعی نیز باقی است.
