- **تاریخ:** ۲۰۲۶-۱۰-۳۰
- **مبنا:** وب‌سایت `dev` در `9d7116389ee75d317ff77b124330be3aa9e0d8e8`؛ Vault `dev` در `c51e087f206b235987987906c62ea4a0ed689967`؛ مشخصات VPS طبق گزارش کاربر، بدون دسترسی به سرور.
- **وضعیت:** تغییرات در PR این نشست؛ وضعیت CI و ادغام در GitHub بررسی شود. نمونهٔ آزمایشی به‌معنای آمادگی استقرار نیست.

## خلاصه و اقدامات

ایمیج Next.js production، Compose مجزای آزمایشی PostgreSQL و media، baseline migration نسخه‌بندی‌شده، دستورهای migration/seed تک‌اجرا، healthcheck و noindex آماده شدند. حالت preview ارسال ایمیل را غیرفعال می‌کند. دربارهٔ proxy هیچ فرض یا تصمیم نهایی نشده و گزارش زیرساخت reverse proxy فعالی پیدا نکرده است. جزئیات در [برنامهٔ پیش‌نمایش](../preview-deployment-plan.md) است.

## منابع و ریسک‌ها

- گزارش زیرساخت: ۴ CPU، حدود ۵٫۸ GiB RAM و ۵۳ GiB دیسک آزاد؛ در یک نمونه ۱٫۷ GiB RAM در دسترس. کفایت VPS هنوز تأیید نشده است.
- آمار CI شامل اندازهٔ ایمیج و نمونه‌برداری RAM کانتینرها و تغییر کل RAM/دیسک runner حین build است؛ ابزار Docker build معمولی RAM اختصاصی build را مستقیم اندازه نمی‌گیرد. ظرفیت VPS از این عددها نتیجه‌گیری قطعی نمی‌شود.
- preview هنوز به proxy واقعی، TLS، عدم bypass، حفاظت کل مسیرها، اعتبارسنجی origin، راهبرد backup/restore، بررسی امنیت لاگ و تصمیم‌گیری دربارهٔ انتقال ایمیج نیاز دارد. خطای schema یا DB قدیمی باید بازبینی شود؛ migration تازه روی DB تولیدی موجود فرض نشده است.
- در Basic Auth، همان `Authorization` مورد استفادهٔ Payload برای Bearer مصرف می‌شود؛ آزمون proxy جداگانه در CI جایگزین انتخاب و آزمون روش احراز هویت واقعی نیست.
- تا تأیید زیرساخت و دستور جداگانه هیچ VPS یا DNS تغییر داده نشده و هیچ استقراری انجام نشده است. فرم‌ها، اتصال‌ها و انتشار عمومی خارج از محدوده باقی ماندند.

## تصمیم و پیگیری Vault

انتخاب proxy و حفاظت، مسیر registry/انتقال ایمیج، سیاست credential و backup و کفایت منابع باید با دستیار زیرساخت و مالک مشخص شوند. تغییر تصمیم‌های معماری در صورت نیاز ابتدا در نشست Vault تأیید و ثبت شود؛ Vault در این نشست تغییر نکرد.
